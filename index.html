How this web edition measures latency. Browsers are not allowed to send ICMP ping packets, so this page times a small HTTPS request to each host instead. After the first (warm-up) request, the connection is reused and each reading is approximately one network round trip plus a little server processing time, so values are usually slightly higher than ping. Statistics use the last 60 readings, exactly like the Python program. For ICMP measurements, a local gateway and the full CSV log, run the Python program from the GitHub repository: python latency_monitor.py.
